# CheckBot: Telegram-бот для автоматической выдачи доступа в канал через AI-проверку скриншотов

CheckBot — это современный Telegram-бот на Python 3.10+ (`python-telegram-bot` v20+), проверяющий выполнение условий (подписка, оплата, репост и др.) по двум скриншотам с помощью нейросетей **Google Gemini API** (по умолчанию, модель `gemini-2.5-flash`) или **OpenAI GPT-4o**. При подтверждении условий бот автоматически генерирует персональную ссылку для входа в закрытый Telegram-канал и заносит пользователя в базу данных SQLite. В проект также встроен веб-дашборд на FastAPI для администратора и оперативная кнопка связи с поддержкой.

---

## 🚀 Возможности

- **Поддержка Google Gemini API и OpenAI**: По умолчанию используется официальный SDK `google-genai` и быстрая мультимодальная модель `gemini-2.5-flash`. При необходимости можно переключить на `gpt-4o`.
- **Кнопка связи с администратором**: На этапе проверки, при отказе или при возникновении вопросов пользователю доступна инлайн-кнопка «💬 Связаться с администратором» для прямого перехода в диалог.
- **Обработка альбомов и одиночных фото**: Поддержка как одновременной отправки двух фото в одном сообщении (медиа-группа/альбом), так и пошаговой отправки.
- **Генерация инвайт-ссылок**: Автоматическое создание ссылок через метод `bot.create_chat_invite_link` с настраиваемым сроком жизни и лимитом входов (одноразовая или многоразовая).
- **База данных SQLite (WAL-режим)**: Хранение пользователей, статусов, ссылок и полной истории попыток верификации.
- **Веб-панель администратора**: Адаптивный веб-интерфейс на FastAPI с защитой по паролю (HTTP Basic Auth), поиском, фильтрами и просмотром AI-логов.
- **Логирование и обработка ошибок**: Логирование всех событий и корректный перехват исключений без падения бота.

## 🛠️ Установка и настройка

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.10 или выше. Рекомендуется использовать виртуальное окружение:

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка файла `.env`
Скопируйте пример настроек и заполните свои значения:
```bash
cp .env.example .env
```

Параметры в `.env`:
| Переменная | Описание | Пример |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) | `123456789:ABCdefGhI...` |
| `CHANNEL_ID` | ID закрытого канала (числовой или юзернейм) | `-1001234567890` |
| `ADMIN_TELEGRAM_USERNAME` | Юзернейм администратора для кнопки связи | `@my_support_tg` |
| `AI_PROVIDER` | AI-провайдер: `gemini` или `openai` | `gemini` |
| `GEMINI_API_KEY` | API-ключ Google AI Studio | `AIzaSy...` |
| `GEMINI_MODEL` | Модель Gemini | `gemini-2.5-flash` |
| `OPENAI_API_KEY` | API-ключ OpenAI (если выбран провайдер `openai`) | `sk-proj-...` |
| `INVITE_LINK_EXPIRE_HOURS` | Время жизни ссылки в часах (`0` — бессрочная) | `24` |
| `INVITE_LINK_MEMBER_LIMIT` | Лимит использований ссылки (`0` — безлимит, `1` — одноразовая) | `0` |
| `VERIFICATION_CRITERIA` | Текстовые инструкции для AI | Текст проверки |
| `WEB_PORT` | Порт веб-дашборда | `8080` |
| `ADMIN_USERNAME` | Логин администратора для веб-панели | `admin` |
| `ADMIN_PASSWORD` | Пароль администратора для веб-панели | `supersecret` |

## ⚠️ Важно: Настройка прав бота в канале

Чтобы бот мог автоматически генерировать пригласительные ссылки:
1. Добавьте вашего бота в целевой закрытый канал.
2. Назначьте бота **Администратором** канала.
3. Обязательно включите боту право **«Приглашать пользователей через ссылки»** (Invite Users via Links).
4. Укажите правильный `CHANNEL_ID` в файле `.env` (для закрытых каналов ID обычно начинается с `-100...`).

## ▶️ Запуск

### Запуск бота и веб-панели одновременно (рекомендуется):
```bash
python main.py
```
- Telegram-бот начнет прием сообщений.
- Веб-панель будет открыта по адресу: `http://localhost:8080` (логин и пароль берутся из `.env`).

### Запуск только бота:
```bash
python main.py --bot-only
```

### Запуск только веб-панели:
```bash
python main.py --web-only
```

## 📱 Сценарий работы пользователя

1. Пользователь нажимает `/start` в боте и получает приветствие с правилами.
2. Пользователь прикрепляет 2 скриншота (одним альбомом или по очереди).
3. Бот показывает статус ожидания и отправляет изображения в GPT-4o.
4. **Успех**: Пользователь получает одобрение с комментарием нейросети и индивидуальную ссылку для входа в канал.
5. **Отказ**: Пользователь получает понятный комментарий от GPT-4o с указанием, что именно сделано не так (например, отсутствует подписка или не видно сумму), и может отправить новые скриншоты.
